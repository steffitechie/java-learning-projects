# Exercise 02 - Updated Points

## About the Project

The goal of this program is to practice changing the value assigned to an existing variable. The program asks for the player's name, current points, and bonus points. It then uses this information to print a player profile showing the previous and updated points.

## Example Output

```text
What is your player name?
Steffitechie
How many points do you have?
100
How many bonus points did you earn?
11

╭──────────.★..─╮
  PLAYER PROFILE
╰─..★.──────────╯
Player: Steffitechie
Previous points: 100
Updated points: 111
```

## What I Practiced

- Updating an existing variable without declaring it again.
- Using a compound assignment operator (`+=`).

## What I Learned

I learned how to write shorter and clearer code by using `points += bonusPoints;` instead of `points = points + bonusPoints;`. 
Also, I've learned that a variable's data type is only written when declaring it, not when updating its value.
